# 🧠 BrainGym

Бесплатные онлайн-игры для тренировки мозга: память, внимание, скорость счёта.
Без рекламы, без регистрации, без paywall. Прогресс хранится у самого пользователя.

> Рабочее название — «BrainGym». Финальное имя выберем до публичного запуска;
> меняется в одном месте (`locales/*.json`, ключ `app.title`).

## Что уже работает (MVP, 16.10.2026)

- **3 игры**: «Счёт на скорость», «Найди пары», «Цвет и слово»
- **6 языков**: RU / EN / ES / DE / FR / ZH (новый язык — один JSON-файл, см. ниже)
- **Прогресс**: XP, уровни, серия дней (streak), личные рекорды, история партий
- **Экспорт/импорт прогресса** в файл — перенос между устройствами без аккаунта
- **Шаринг результата** (Web Share / копирование в буфер)
- **Светлая и тёмная темы**, адаптив под телефон

Чего ещё нет (и не притворяемся): аккаунтов, глобальных лидербордов, офлайн-PWA, донатов.
План — в [ROADMAP.md](ROADMAP.md).

## Запуск локально

Нужен любой статический сервер (ES-модули не работают по `file://` — это важно):

```bash
./run.sh            # http://localhost:8765
```

или:

```bash
python3 -m http.server 8765
```

Открыть: **http://localhost:8765**

## Проверка (для разработки)

Сквозной тест в реальном браузере (headless Chrome через CDP): открывает сайт,
кликает по ответам, доводит партию до конца, проверяет прогресс, профиль и смену языка.

```bash
node tools/smoke.mjs http://127.0.0.1:8765   # сервер должен быть запущен
```

Ожидаемый результат: `ИТОГ: 9/9 проверок пройдено`, скриншоты — в `.smoke/`.

## Структура

```
index.html           — каркас страницы (шапка, футер)
css/style.css        — вся вёрстка и темы
js/app.js            — роутер, экраны «Игры» и «Прогресс»
js/core/i18n.js      — система переводов
js/core/progress.js  — прогресс, XP, серии, экспорт/импорт
js/core/ui.js        — утилиты (тосты, формат, шаринг)
js/games/registry.js — список игр
js/games/*.js        — игры, каждая — один модуль
locales/*.json       — переводы (6 языков)
docs/                — архитектура и монетизация
```

## Как добавить игру

1. Файл `js/games/<id>.js` экспортирует объект:

   ```js
   export default {
     id: 'mygame',
     start(view, ctx) {
       // рисуем UI в view (DOM-элемент)...
       return { destroy() { /* очистка таймеров/слушателей */ } };
     }
   };
   ```

2. В конце партии вызвать `ctx.finish({ score, xp, correct, total, durationSec })` —
   прогресс запишется сам (XP, рекорд, история, серия дней).
3. `ctx.exit()` — назад к списку игр. `ctx.t(key)` — переводы.
4. Добавить игру в `js/games/registry.js` и строки `game.<id>.title` / `game.<id>.desc`
   во ВСЕ `locales/*.json`.

## Как добавить язык

1. `cp locales/en.json locales/<код>.json` → перевести значения.
2. Добавить код и название языка в `LANGS` в `js/core/i18n.js`.

## Принципы проекта

1. Игры бесплатны навсегда. Никакой рекламы, никаких paywall.
2. Минимум данных: чтобы играть, аккаунт не нужен.
3. Прогресс принадлежит пользователю: экспорт в файл из коробки.
4. Закрепляем договорённости кодом, числами и документами, а не «на словах».
