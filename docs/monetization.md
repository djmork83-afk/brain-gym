# Монетизация: приём денег при разработчике в РФ

> Статус: **не блокирует разработку**. Все игры бесплатны; донаты — необязательная
> благодарность. Условия платёжных сервисов меняются часто: перед публичным запуском
> донатов **перепроверить каждый канал на актуальной дате** (данные ниже — из обзоров
> 2025 г. и требуют подтверждения).

## Принципы

1. Игры бесплатны навсегда. Донат **ничего не открывает** — это чистое «спасибо».
2. Сайт сам не обрабатывает платежи и не хранит платёжные данные — только кнопки-ссылки
   на внешние сервисы. Меньше кода — меньше рисков и юридических вопросов.
3. Никакой рекламы и продажи данных.

## Каналы (кратко)

| Канал | Кто может заплатить | Вывод автору | Комиссия* | Нюансы |
|---|---|---|---|---|
| **Boosty** | карты РФ и зарубежных банков, ЮMoney | на карту РФ / ЮMoney | ~10% + вывод | основа для РФ-аудитории; англ. версия сайта есть |
| **Sponsr** | карты РФ и зарубежных банков | только РФ-счёт / ЮMoney | ~10% + 0,7–10% | есть поиск авторов внутри платформы |

\* Комиссии — порядок величины по обзорам 2025 г.; уточнять в договоре.

## Что НЕ подходит

- **Patreon** — заблокирован в РФ (с 2022), выплаты в РФ недоступны.
- **Stripe / PayPal / Ko-fi / Buy Me a Coffee / GitHub Sponsors** — как получатель из РФ
  не подключаются (Stripe и PayPal не работают с РФ-аккаунтами; Ko-fi и GitHub Sponsors
  упираются в выплаты через неработающие в РФ шлюзы).
- **ЮMoney** — рабочий вариант, но у него ограниченная международная приёмка
  (только там, где провайдер позволяет); как «сеть на всякий случай» — можно.

## Рекомендация на фазу 4

1. **Boosty** — основной канал (простая ссылка «Поддержать»).
2. **TON-адрес** («Можно поддержать в TON: UQ…», QR-код) — для международной аудитории
   без посредников и без санкционных барьеров.
3. Опционально **Capusta.Space** — если захочется виджет донатов прямо на странице.
4. Налоги: донаты-пожертвования физических лиц и НПД — тёмная зона; подписки — 4% НПД
   с физлиц. Перед запуском — короткая консультация (не юридическая консультация в этом файле).
